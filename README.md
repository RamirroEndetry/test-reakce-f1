# Test reakce – překonej pilota Formule 1

Jednoduchá webová aplikace pro měření reakční doby ve třech kolech.
Cílový čas: 201 ms (Valtteri Bottas, start VC Rakouska 2017).

Spuštění: otevřete `index.html` v prohlížeči, nebo použijte GitHub Pages.

- Žebříček se ukládá v prohlížeči (localStorage).
- Reset žebříčku: na obrazovce výsledků stiskněte Ctrl+Shift+Delete.
- Celá obrazovka: tlačítko ⛶ vpravo dole nebo F11.
